# 怪文書記録（公開版）

元のサイト（claude.ai のうちの子帳）と同じページを、**見るだけ**で公開したものです。
「全体公開」と「合言葉つき」の記事が入っています。合言葉つきの記事は暗号化されたままで、合言葉を入れた人だけが読めます（合言葉そのものは入っていません）。非公開の記事と、夢創作（ジャンルが夢創作のフォルダ）の記事・フォルダは入っていません。検索エンジンには載らない設定です。

- `index.html` … 元のサイトと同じページ。保存先の代わりに `data.json` を読みます
- `p/記事ID.html` … 記事ごとの共有用ページ。Xなどにはカード画像を見せ、開いた人はその記事へ移ります
- `tools/` … 書き出しの仕組み（`gen2.py` でページとデータ、`og.js` でカード画像を作ります）

記事の追加・編集は元のサイトで行い、この公開版は書き出し直して更新します。
